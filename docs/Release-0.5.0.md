# Blue Network 0.5.0 — ergonomic UI, chat and game overlay

- Connection controls appear on the network page only. Joining a network can request the VPN permission and continue to the join dialog after connection. Network creation continues to work without a Windows gateway.
- Device search matches names and virtual IPs. Traffic totals are on the device page. Existing Russian/English language and light/dark/system themes are retained.
- Private one-to-one text chat between updated Blue Network clients, including an embedded overlay chat and editable quick phrases. Official Windows Radmin VPN does not implement this application protocol and cannot receive these messages. No automatic sending, public chat server, Windows companion or file attachments are provided.
- Chat uses IPv4/UDP port 49826 inside the existing authenticated Radmin transport; no physical-network listener is opened. The app's excluded Android UID does not bypass the VPN path: packets are injected into the private Radmin mux endpoint. Ordinary app-originated TUN traffic to the reserved chat port is dropped, so other Android apps cannot inject chat through normal VPN sockets. Incoming packets require strict length, IPv4, recipient, non-fragmentation, UDP checksum and UTF-8 validation. Sender must be a currently connected native peer sharing a joined network. Frames also pass the native engine's authenticated peer/source validation.
- Messages are at most 400 UTF-16 code units and 900 encoded wire bytes. At most eight sends may be awaiting confirmation. Three transmission attempts over seven seconds; delivery requires a matching ID and source peer ACK. A missing ACK means delivery is unconfirmed, not proof the message was not received. Queue/rate limits bound processing. The sender's displayed name comes from native peer state, not message text.
- History is local, AES-GCM encrypted with Android Keystore, limited to 48 records and 56 KB plaintext. Text never enters diagnostics or error logs. Clearing history affects this phone only. Corrupt encrypted history is retained and prevents new writes until the user explicitly clears it. Storage is excluded from backup and source archives.
- Floating circle needs Android's Display over other apps permission. Enable it from the network page or settings. Tap to expand; drag to move; minimize or close with visible controls; Hide circle is also available in its foreground notification. The service is unexported, not sticky, does not start at boot and does not read/capture other applications. Overlay chat is protected with FLAG_SECURE. Android and some games may suppress overlays on protected screens.
- Automatic connect actions use an unexported activity; arbitrary extras sent to the public launcher cannot start the VPN.
- Quick controls include opening the app/connecting, disconnecting, copying your own VPN IP and keeping the screen awake while the app or overlay is visible. Screen-on mode can increase battery consumption and is off by default.

Validation covers the disposable Android 15 x86_64 emulator and synthetic peer traffic. Real two-phone interoperability, physical ARM overlays, OEM battery restrictions, long roaming sessions and accessibility screen-reader behavior require device testing. The existing network/native binaries are unchanged from 0.4.0. This release does not claim the absence of all vulnerabilities, change Radmin's server-side network administration capabilities, or add system Always-on lockdown support.
