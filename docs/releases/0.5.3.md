# Синяя сеть 0.5.3

## Изменения

История изменений в приложении и документация выпусков приведены к единому официальному стилю. Полный список на русском и английском языках: [заметки выпуска](../github-releases/v0.5.3.md).

Добавлены исходники option-ext 0.2.0 и сведения об их получении в соответствии с MPL-2.0. Сетевые нативные библиотеки и формат пользовательских данных не изменялись.

## Проверки

Для этого редакционного выпуска выполняются сборка APK, Android Lint, проверка подписи и выравнивания, проверка синхронизации текстов GitHub и приложения, сравнение нативных библиотек с 0.5.2. Полный Android-прогон из 28 групп выполнен для 0.5.2; он не выдаётся за новый прогон версии 0.5.3.

## Обновление

Установите APK поверх предыдущей версии. Подпись и идентификатор приложения сохранены. Удаление данных приложения не требуется.
