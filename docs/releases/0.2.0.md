# Синяя сеть 0.2.0

Релиз для прямой установки APK, Android 8.0+, ARM64/ARM32/x86-64. Установите поверх 0.1.0: package и ключ подписи прежние; удаление данных/переустановка не нужны.

Новые функции: ограниченное автопереподключение сохранённого устройства и экспорт диагностики без идентификаторов и секретов. Настройки находятся в русском интерфейсе в синих цветах.

Исправления и ограничения описаны в CHANGELOG.md и SECURITY-REVIEW.md. Подключение к Windows/Minecraft подтверждено пользователем для 0.1.0, новая версия требует повторной полевой проверки. Сервис не обещает always-on или kill switch.

Файлы: BlueNetwork-0.2.0.apk, BlueNetwork-0.2.0-source.zip и SHA-256. Приватный ключ подписи и локальные профили в архив не включены.
