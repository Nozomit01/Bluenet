# Синяя сеть 0.3.0

APK Android 8.0+, ARM64/ARM32/x86‑64. Установите поверх 0.2.0; package/signing key не изменились, профиль и IP сохраняются.

В настройках импортируйте vless:// из Happ, включите «Radmin + VLESS», отключите Happ. Нельзя запустить два отдельных Android VPN; вместо этого трафик разделяется внутри одного туннеля. Сервер пользователя в облаке не тестировался. Локальные TCP/UDP и Android process/fd/mux проверены отдельно. TLS/Reality используют Xray; конкретные профили требуют проверки.

Создание сети доступно с телефона, ПК для него не требуется. Русский/English, light/dark/system themes, диагностика, журнал и измеренное качество соединения — в интерфейсе.
