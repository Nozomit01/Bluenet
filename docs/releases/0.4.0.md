# Синяя сеть 0.4.0

APK Android 8+, ARM64/ARM32/x86-64. Обновление поверх 0.3.0 с тем же ключом и сохранением профиля Radmin/IP. Выбор приложений требует Android 10+.

Настройки → «Подписки и серверы VLESS»: импорт vless:// либо HTTPS-подписки plain/Base64, обновление, выбор и проверка серверов. До 24 поддерживаемых записей; остальные протоколы пропускаются. Подписка обновляется раз в сутки по расписанию Android (может откладываться системой), действует при следующем подключении. Ошибка обновления сохраняет старые данные.

Включите «Radmin + VLESS», отключите Happ. В «Приложениях через VLESS» можно выбрать приложения; Radmin доступен всем, DNS и неопознанные потоки идут через VLESS. Пустой выбор означает весь интернет через VLESS. Для применения настроек сначала отключите VPN.

«Проверить все серверы» проверяет реальный VLESS/TLS/HTTP-путь к www.gstatic.com, затем автоматический режим выбирает самый быстрый свежий успешный замер. При трёх сбоях активного пути подряд (проверки каждые 30 сек) выбирает резервный сервер и переподключается, не более пяти попыток. При отсутствии измерений остаётся выбранный сервер; нельзя утверждать, что он самый быстрый.

Kill switch включён по умолчанию в объединённом режиме и удерживает блокировку при сбоях/переподключении, пока служба работает. Ручное отключение, отзыв разрешения, force-stop/crash/убийство службы Android снимают защиту. Системный Always-on/lockdown пока не поддержан.

«Устройства» → «Игры и избранные устройства»: избранное, копирование IP, TCP-проверка порта по Radmin; для Java Minecraft часто 25565, LAN-мир может использовать другой порт. UDP/Bedrock не проверяется.

Меню сети → «Приглашение в сеть · QR»: название и необязательный пароль, QR-код/копирование приглашения. Получатель сканирует системной камерой или вставляет приглашение и подтверждает вступление. Пароль в QR даёт доступ, не публикуйте его. Для создания сети ПК не нужен.

В редакторе шторки Android добавьте плитку «Синяя сеть». Первый запуск может открыть приложение для VPN-разрешения.

Диагностика показывает историю RTT/колебаний и долю проверок без ответа за 10 минут, до 128 результатов. Это потери проверочных запросов, не всех игровых пакетов.

## Чего пока нет из управления Radmin

- Удаление сети владельцем (есть только выход).
- Исключение/блокирование участников, ручное подтверждение заявок.
- Смена пароля/прочих параметров существующей сети и отдельные имена для участников.
- Каталог публичных игровых сетей.
- Автозапуск после перезагрузки, системный Always-on/lockdown.

Прямые TCP/UDP, relay, join/create/leave, участники, смена имени своего устройства и ping уже реализованы. Чата в приложении нет. Удалённый рабочий стол и передача файлов — отдельный коммерческий Radmin, не транспорт Radmin VPN.

Проверки и ограничения: verification.json, SECURITY-REVIEW.md. Синтетические Android проверки не заменяют тест на вашем реальном телефоне/сервере Happ.
