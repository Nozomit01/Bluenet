# Синяя сеть 0.5.1

- Нижняя навигация получила отдельные значки и однострочные подписи. Длинное название не разрывается посреди слова; полная подпись доступна средствам доступности.
- Кнопки чата больше не стоят вплотную, системная анимация теней не накладывает их друг на друга. Ввод и отправка находятся в отдельной строке; прокручивается история сообщений.
- При небольшой доступной высоте экрана быстрые фразы открываются компактной кнопкой «+» возле сообщения. Текстовые кнопки используют адаптивную высоту, а значки не увеличиваются вместе с системным шрифтом.
- Настройки → «Что нового»: офлайн-патчноуты всех выпущенных версий0.1.0–0.5.1 на русском и английском. Список начинается с текущего обновления.
- UI-проверки охватывают ширину320dp, масштаб шрифта100/150/200%, светлую/тёмную тему, два языка, высоту чата400/240dp и компактный чат кружка. Синтетические данные; реальный Radmin-сервер в тестах не используется.

Сетевые нативные библиотеки не менялись. Чат по-прежнему предназначен для обновлённых Android-клиентов «Синей сети», без совместимости с Windows Radmin.

Для каждого следующего обновления добавляйте запись в начало `app/src/main/assets/release-notes.json`, заполняйте ru/en, повышайте versionCode/versionName и проверяйте, что история включает все предыдущие выпуски. Указывайте только подтверждённые даты. Приватные ключи и настройки пользователей в исходники не включаются.
