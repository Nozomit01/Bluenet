# Синяя сеть 0.5.2

Главный экран компактнее, настройки сгруппированы по назначению, а вспомогательные экраны используют единое синее оформление. Области нажатия значков увеличены.

Во время проверки инструментов отображается состояние работы; кнопка «Назад» остаётся доступной. При возврате из управления VLESS настройки обновляются. В чате понятнее выбор получателя и состояние отсутствующего подключения. Новые сообщения и статусы доставки не прокручивают историю вниз, пока пользователь читает выше; отправка своего сообщения возвращает к концу.

История обновлений: Настройки → «Что нового», на русском и английском, без интернета.

Сетевые протоколы, нативные библиотеки и формат защищённых пользовательских данных не менялись. Чат поддерживается между обновлёнными Android-клиентами «Синей сети», без совместимости с Windows Radmin.

Отчёты проверок и снимки экранов находятся в release-verification архива исходников. Эмуляторные проверки используют синтетические данные; они не заменяют проверку на физических телефонах и реальном сервере пользователя.
