# 0.6.0 — 2026-10-19

### Русский

**Помощник подключения, игровые карточки и доступность**

- Добавлен помощник для сценариев «Не вижу друга» и «Друг виден, игра не подключается»: наблюдаемое состояние VPN и сети, следующие действия и проверка указанного игрового TCP-порта через Radmin.
- Добавлены карточки игровых миров в Android-чате: предпросмотр названия игры, адреса, порта, автора и времени перед отправкой выбранному получателю; копирование адреса, обновление новой карточкой и локальное удаление.
- Добавлены нецветовые признаки состояния и ограниченные уведомления TalkBack на открытом экране «Сети». Устаревшие объявления отменяются, частые изменения объединяются.
- Добавлены отключённые по умолчанию вибросигналы статуса с TalkBack с учётом системных настроек звука и вибрации.
- TCP-проверка не устанавливает причину таймаута и не подтверждает работу UDP или совместимость игры. Карточка содержит сведения хозяина и не подтверждает доступность сервера; копии у получателя не отзываются локальным удалением.

### English

**Connection assistant, game cards and accessibility**

- Added an assistant for “I cannot see my friend” and “Friend is visible, but the game cannot connect”: observed VPN and network state, suggested next steps and a specified game TCP port check through Radmin.
- Added game world cards in Android chat: preview of game, address, port, author and time before sending to the selected recipient; address copying, updates as new cards and local deletion.
- Added non-color status cues and bounded TalkBack announcements on the open Networks screen. Stale announcements are cancelled and frequent changes are combined.
- Added opt-in status vibration with TalkBack, respecting system sound and haptic settings. Vibration is off by default.
- A TCP check does not identify the cause of a timeout or confirm UDP operation or game compatibility. A card contains host-supplied details, not proof of availability; local deletion does not recall recipients’ copies.
