# Синяя сеть / Blue Network

Неофициальный Android-клиент сетей Radmin VPN на основе OpenRad. Поддерживает подключение к существующим сетям, создание сетей и работу Radmin совместно со встроенным VLESS в одном Android VPN-туннеле.

Проект не связан с Famatech и не является официальной Android-версией Radmin VPN.

## Возможности

- Создание сетей и подключение по имени и паролю.
- Список устройств, копирование IP-адресов, измерение задержки и проверка игрового TCP-порта.
- Помощник при проблемах подключения с объяснением наблюдаемых результатов и следующего шага.
- Импорт VLESS-ссылок и HTTPS-подписок, выбор сервера и приложений для интернет-трафика.
- Текстовый чат и карточки игровых миров между совместимыми Android-клиентами «Синей сети».
- QR-приглашения, плавающая панель управления и плитка быстрых настроек Android.
- Русский и английский интерфейс; светлая, тёмная и системная темы; нецветовые признаки состояния и уведомления TalkBack на открытом экране «Сети».
- Журнал ошибок и экспорт диагностики по действию пользователя.

## Установка и обновление

Текущая версия: **0.6.0**. Требуется Android 8.0 или новее. Поддерживаемые архитектуры: ARM64, ARM32 и x86-64.

Готовый APK и контрольная сумма доступны на странице [GitHub Releases](https://github.com/Nozomit01/Bluenet/releases/latest) и в каталоге [releases/](releases/).

1. Скачайте `BlueNetwork-0.6.0.apk` и установите приложение. При необходимости разрешите установку APK для используемого браузера или файлового менеджера.
2. Нажмите «Подключиться» и подтвердите системный запрос на создание VPN.
3. Нажмите «Войти в сеть» и введите её имя и пароль либо создайте новую сеть.
4. Подключите остальные устройства к той же сети.

Для обновления установите APK поверх предыдущей версии. Подпись опубликованных обновлений сохраняется. Не удаляйте данные приложения: они содержат профиль устройства.

## Совместная работа Radmin и VLESS

Импортируйте `vless://` или HTTPS-подписку в разделе настроек подключения и включите «Radmin + VLESS». Изменение режима и профилей выполняется при отключённом VPN.

Android поддерживает один активный VPN-туннель на профиль пользователя. Для совместной работы используется встроенный VLESS; отдельное приложение VPN, включая Happ, необходимо отключить. Зашифрованные ссылки `happ://` не поддерживаются.

Описание подписок, маршрутизации и выбора приложений: [руководство по подключениям](docs/releases/0.4.0.md).

## Ограничения

- Совместимость со всеми играми, устройствами и сетями не гарантируется. Работа broadcast/multicast зависит от игры и Android.
- Канал Radmin передаёт IPv4; приложение не предоставляет полную виртуальную Ethernet-карту.
- Чат предназначен для совместимых Android-клиентов «Синей сети» и не поддерживает чат Windows Radmin.
- Системные режимы Always-on VPN и lockdown не поддерживаются. Защита при сбое действует, пока работает VPN-служба; ручное отключение и завершение службы снимают блокировку.
- Эмуляторные проверки не заменяют проверку на физических телефонах и реальных серверах.

Подробности: [SECURITY-REVIEW.md](SECURITY-REVIEW.md).

## История изменений

[CHANGELOG.md](CHANGELOG.md) содержит все выпуски на русском и английском языках. Тексты GitHub Releases находятся в [docs/github-releases/](docs/github-releases/). В приложении доступен раздел «Настройки → История изменений».

## Сборка

Для полной сборки требуются Linux x86-64, JDK 21, Rust, Go 1.27.2, Android SDK Platform 35, Build Tools 35.0.0 и NDK 27.2.12479018. Версии зависимостей закреплены в Cargo.lock, go.mod и go.sum.

```bash
export ANDROID_HOME=/path/to/android-sdk
export JAVA_HOME=/path/to/jdk-21
export GO_BIN=/path/to/go/bin/go
rustup target add aarch64-linux-android armv7-linux-androideabi x86_64-linux-android
./build-apk.sh
```

Результат: `dist/BlueNetwork-0.6.0.apk`. Для сборки Java-оболочки с включёнными в репозиторий нативными библиотеками:

```bash
python3 create-signing-key.py
./gradlew --no-daemon :app:assembleRelease :app:lintRelease
```

Скрипт создаёт или использует приватный ключ в `.signing/`. Храните его локально для последующих обновлений. Другой ключ не позволяет обновить установленный APK с прежней подписью.

## Проверки

Instrumentation-проверки находятся в `app/src/androidTest/`. Они используют синтетические данные и предназначены только для отдельного тестового эмулятора. В выпуске 0.5.2 на Android 15 / API 35 x86-64 пройдены 28 групп проверок. В выпуске 0.6.0 проверена 31 уникальная группа в двух прогонах одного подписанного APK (27 базовых + 4 группы интерфейса и новых функций); единого полностью успешного прогона не было. В одном повторном прогоне зафиксирован неразобранный сбой запуска сетевого движка. Полные журналы и ограничения опубликованы в verification/0.6.0. Проверки новых функций и ограничения выпуска 0.6.0 описаны в [документации выпуска](docs/releases/0.6.0.md).

```bash
./gradlew --no-daemon :app:assembleRelease :app:assembleAndroidTest :app:lintRelease
```
